This is a React-based Weather Application built using modern React features and external APIs. The app allows users to search for a city and fetch real-time weather data using the Weather API.

Users can toggle the search input, view current temperature, weather condition, local time, and location details. The interface also displays additional weather information such as humidity, wind speed, pressure, visibility, UV index, and other atmospheric details, presented with a clean UI and weather-related icons.

This project is designed to practice API integration, React state management, and dynamic UI rendering.
